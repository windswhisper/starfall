# 海克斯自动演示

双击 `start-demo.cmd`，启动项目内 `build/hex-demo/runtime` 的独立游戏副本。当前副本已组装完成，使用远征的游戏资源；不要将演示 DLL 覆盖到日常游戏目录。

演示自动展开科研卡片，按固定顺序展示“坦克引擎、爆炸蜘蛛、履带升级”，随后选择第一张“坦克引擎”。本轮只购买这一项，用于展示击杀后的体型和弹体成长：每次击杀后生命上限提高 30%，体型和弹体增加原始尺寸的 15%，最多成长 20 次。100 辆友军犀牛坦克从四个点位各以超时空方式刷出 25 辆，由地图小队脚本控制进攻；100 辆敌军灰熊坦克以五道间隔排列的横线原地防守，地图将其移动速度设为 0，仍可转动炮塔开火。友军在第 10 个地图计时单位同时出场，镜头由地图时间触发器切换；启动后无需操作。

正常启动不会在测试结束帧退出，结束观看可从游戏菜单退出。运行目录中的 `Starfall.HexDemo.test` 是开发测试开关，启动入口会移除它；启用该开关时会截取卡片和战斗画面、写入测试日志，并在第 700 帧退出。

## 文件

- `Starfall_HexDemo.map`：单位、防线、四组进攻小队与镜头触发器。
- `Starfall.ini`：仅注册三项科研，初始 100 点，关闭自动产点和刷新。
- `Demo.cpp`：演示专用自动点击及测试截图逻辑。
- `build-demo.cmd`：在项目根目录编译演示 DLL，输出到 `build/hex-demo/Starfall.dll`；重新编译后需复制到独立运行目录才能生效。
