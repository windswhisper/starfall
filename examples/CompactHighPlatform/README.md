# 苏军小型高台

**Fortified High Platform** 位于苏军防御栏，需要苏军建造场和磁能反应炉。造价 1500，生命值 2500，护甲为 `concrete`。

- 建筑外圈为 3×3，占用八格墙体，中央一格台面抬高四级。九格都须平坦、同高且可建造，可以混用规则允许建造的不同地形。
- 选中己方地面步兵或载具，点击小型高台墙面进入。选中高台后按部署键（默认 D）可让台面单位下台。
- 高台无法出售。摧毁时播放与苏军建造场相同的爆炸和碎片效果。
- 墙顶的红色标识带使用玩家的阵营色。

使用包含 ActSp 的新版 `Starfall.dll`。通过 Ares 分别引入 `CompactHighPlatform.rules.ini` 和 `CompactHighPlatform.art.ini`，并将两张 SHP 和六个 `ascp*.pal` 文件放在游戏根目录。新对局中可按上述前置建造。
