# 地图触发动作

[返回目录](../index.md)

地图触发可通过动作编号发放科研点、授予预设中的被动，或执行地图 Lua 预设。动作需要配置在已有的地图触发器中，并配合原版事件和标签使用。

配置位置：地图文件（`.map`）中的触发动作，或地图编辑器对应的触发动作界面。

| 动作编号 | 功能 | 参数 3 | 参数 4 |
| --- | --- | --- | --- |
| `9600` | 发放科研点 | 要发放的正整数点数 | 玩家选择值 |
| `9601` | 授予被动预设 | 已注册的[授予预设编号](grant-presets.md) | 接收对象选择值 |
| `9602` | 执行地图 Lua | 已注册的[地图 Lua 预设编号](lua-presets.md) | 玩家选择值 |

## 玩家选择值

| 参数 4 | 选择范围 |
| --- | --- |
| `0` | 触发器所属玩家。 |
| `4475`–`4482` | 地图出生位置 1–8 对应的玩家，按顺序对应。 |

动作 `9600` 向选择的有效玩家发放科研点；动作 `9602` 将选择的玩家作为 Lua 回调所属方。该数字是出生位置选择值，不是 Lua 或 DLL 接口中的玩家数组索引。

## 被动接收对象

`9601` 除上述玩家选择值外，还接受以下参数 4：

| 参数 4 | 选择范围 |
| --- | --- |
| `-1` | 与本次触发关联的对象；须为可接收被动的单位或建筑。 |
| `-2` | 地图上标签关联到该触发器的单位或建筑。 |

使用玩家选择值时，`9601` 选择该玩家当前在地图上的单位和建筑，再由预设的类型条件筛选；不会自动授予之后新建的单位。预设参数见[被动授予预设](grant-presets.md)。
