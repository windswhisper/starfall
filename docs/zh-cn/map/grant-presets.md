# 被动授予预设

[返回目录](../index.md)

被动授予预设将被动列表、持续时间和接收类型组合起来，供地图触发动作和小队脚本动作 `9601` 使用。

配置位置：`rulesmd.ini` 或 `Starfall.ini`。

```ini
[Starfall.PassiveGrants]
1=(授予预设 ID)
; 用编号注册预设，供动作 9601 的预设参数引用。
; 编号使用不带前导零的非负十进制整数；合并时使用未占用的编号。

[授予预设 ID]
Passives=(被动或主动技能 ID 列表)
; 指定要授予的已注册被动或主动技能。
; 必填；列表中存在无效 ID 时预设无效。

Duration=(整数帧)
; 指定授予的持续时间。
; 默认值：-1，永久；临时授予填写正整数帧。

TargetTypes=(单位或建筑类型 ID 列表)
; 限制可以接收授予的具体类型。
; 默认值：不限制类型；不支持科研分类选择器，类型 ID 须存在。
```

预设只作用于执行时存活、在地图上且状态允许的对象；满足条件的建筑也可以接收。不填写 `TargetTypes` 时不会为后续出生的单位自动补发。
