# 地图 Lua 预设

[返回目录](../index.md)

地图 Lua 预设把动作编号 `9602` 的数值参数关联到 Lua 脚本和回调函数。Lua 回调所属玩家由地图触发动作的参数 4 指定。

配置位置：`rulesmd.ini`、`Starfall.ini`，或地图文件（`.map`）中的对应节。

```ini
[Starfall.MapScripts]
1=(地图 Lua 预设 ID)
; 用编号注册预设，供地图触发动作 9602 引用。
; 编号使用不带前导零的非负十进制整数；预设 ID 最长 100 字节。

[地图 Lua 预设 ID]
Script=(Lua 文件名)
; 指定已发现的 Lua 脚本文件。
; 必填；省略 .lua 时自动补全。

Function=(函数名)
; 指定脚本导出的回调函数。
; 必填；函数必须存在。

Script.Param.参数名=(数值或文本)
; 向回调传递自定义参数，通过 ctx.params 中的小写参数名读取。
; 可配置多个不同参数名。
```

回调可读取 `ctx.owner`；触发关联的对象可用时提供 `ctx.self`，有效触发位置可用时提供 `ctx.point`。回调开始时没有 `ctx.target`。延迟任务不依赖关联单位存活，但之后访问该单位前仍应检查其有效性。

Lua 接口见[上下文与事件数据](../lua/context.md)和[结果调用](../lua/actions.md)。地图回调遵循序列上下文的结果限制，不能直接假定所有普通被动目标都存在。
