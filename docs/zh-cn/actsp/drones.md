# 子机与地面守卫

[返回目录](../index.md)

子机行为扩展原版飞行器子机的警戒、跟随和绕行；建筑也可以单独管理一个使用普通地面移动方式的守卫。飞行子机仍使用原版子机槽位。

## 子机行为

```ini
[母体类型 ID]
Drone.Mode=(Native、Guard、Follow 或 Orbit)
; 分别使用原版行为、固定格警戒、跟随偏移或围绕母体运行。
; 默认值：Native。

Drone.GuardCell=(整数 X,整数 Y)
; Guard 模式的初始警戒格。
; 默认值：未设置。

Drone.Offset=(整数 X,整数 Y)
; Follow 模式相对母体的地图轴偏移。
; 默认值：2,0；每个分量范围：-32–32 格。

Drone.Radius=(整数格数)
; Orbit 模式的绕行半径。
; 默认值：3；范围：1–32。

Drone.Period=(整数帧)
; Orbit 模式的绕行周期。
; 默认值：180；范围：30–3600。

Drone.GuardRange=(整数格数)
; 警戒位置周围的索敌半径。
; 默认值：5；范围：1–32。

Drone.UseBuildingDocks=(布尔值)
; 允许符合条件的建筑子机或地面守卫使用建筑停机位。
; 默认值：no。
```

飞行子机需要原版子机槽位；没有攻击目标时主动起飞，需要母体当前使用的发射武器配置 `Spawner=yes`。母体指定的目标优先；飞行子机弹药耗尽后使用原版返航和补给。

## 建筑地面守卫

```ini
[建筑类型 ID]
Drone.GroundUnit=(地面步兵或载具类型 ID)
; 为 Guard 模式建筑指定一个地面守卫。
; 默认值：未设置；飞行子机管理器存在时优先使用原版子机槽位。

Drone.GroundRespawnDelay=(整数帧)
; 守卫失去或建筑所属方改变后的补充等待时间。
; 默认值：300；范围：0–1000000。
```

地面守卫使用自身寻路和武器，每个建筑管理一个；出口没有空位时等待。建筑被占领时，旧守卫归原玩家，新所属方在等待后补充守卫；建筑销毁或出售后存活守卫变为普通单位。

## 警戒格与停靠

可用建筑集合点或 Lua 的 `unit:setDroneGuardCell(point)` 设置警戒格，后一次设置覆盖前一次。地面守卫应选择可到达的格子；警戒格和守卫状态随存档保留。

启用建筑停靠时，飞行子机须满足建筑停机位及飞机 `Dock` 等原版要求。地面守卫向建筑地基附近设置集合点可召回停靠；向更远处设置集合点可派出警戒。
