# 相对目标的武器发射位置

[返回目录](../index.md)

武器可以从目标位置附近发射，而不是从开火单位的武器出口发射。该设置不改变原有射程检查、归属或目标跟踪。

```ini
[武器 ID]
FireOrigin=(Firer 或 Target)
; 选择原版武器出口，或使用目标瞄准点作为发射位置。
; 默认值：Firer。

FireOrigin.Offset=(整数 X,整数 Y,整数 Z)
; 对相对目标的发射位置添加固定地图轴偏移，单位为 leptons。
; 默认值：0,0,0；水平方向 256 leptons 为一格，Z 向上。
```

目标为地面时使用目标格表面，包括桥面；偏移后位置超出地图网格时回退普通武器出口。部分特殊武器使用自己的发射系统，不受此设置控制。Lua `FireWeapon` 的 `Origin` 可单独覆盖一次射击的位置。
