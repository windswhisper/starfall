# 主动技能注册与授予

[返回目录](../index.md)

主动技能由玩家选择单位后使用，与被动共用注册表和授予方式。注册只定义技能，单位还须通过类型绑定、科研或其他授予方式获得该技能。

```ini
[Starfall.PassiveTypes]
0=(主动技能 ID)
; 注册主动技能配置节。
; 使用未占用的非负整数编号。

[主动技能 ID]
Trigger=Active
; 将该配置定义为由玩家操作释放的主动技能。
Action=(结果类型)
; 执行主动技能支持的一次性结果，例如 RunScript。

[单位类型 ID]
Starfall.Passives=(被动或主动技能 ID 列表)
; 将已注册技能授予该类型的单位。
; 多个 ID 用英文逗号分隔；合并时保留已有技能。
```

技能也可通过科研的 `GrantPassive` 结果或其他被动的授予结果获得。同一技能 ID 在混合选择中共用一个界面按钮；每个单位的冷却分别计算。

主动技能不支持普通被动的筛选条件、`Chance`、`Actions`、持续状态条件或 `Stack.Max`。释放时使用单个受支持的结果，具体见[技能结果与脚本](results.md)。
