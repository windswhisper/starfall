# 主动技能冷却

[返回目录](../index.md)

冷却按每个技能持有者分别计算，在技能成功生效后开始。界面以游戏秒显示剩余时间并向上取整。

```ini
[主动技能 ID]
Cooldown=(非负整数帧)
; 指定每次成功释放后的冷却时间。
; 默认值：普通脚本及其他技能为 0；JumpTo 和 EjectPassengers 为 120 帧。
```

多个选中单位共用按钮时，只要其中一个持有者可以释放，就不显示倒计时；否则显示最短的剩余冷却。成功执行原生结果、改变持久状态或安排任务可以使脚本释放成功，Lua 仅返回 `true` 本身不会启动冷却。

`Active.InterruptOrders=yes` 在施法者和目标通过检查后、结果执行前中断命令；即使脚本最终没有产生有效结果，也可能已经中断命令。
