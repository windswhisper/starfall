# 数值公式与变量

[返回目录](../../index.md)

公式使用 `$(...)` 包裹，不是 Lua。比较运算结果为 0 或 1；小数和百分比字面量均可使用，例如 `1.5%` 等于 `0.015`。

支持一元 `+`、`-`，算术 `+`、`-`、`*`、`/`，比较 `>`、`>=`、`<`、`<=`、`==`、`!=`，以及 `min(a,b)`、`max(a,b)`、`clamp(x,low,high)`、`floor(x)`、`if(condition,thenValue,elseValue)`。不支持 `&&`、`||`、Lua 的 `and/or` 或连续比较。
