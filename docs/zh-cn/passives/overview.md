# 被动能力简介

[返回目录](../index.md)

被动能力用于给单位或建筑添加自动生效的规则。单位可以自带被动，也可以通过科研、弹头或其他效果获得被动。

事件型被动在指定时机检查条件，然后执行结果；持续型被动在条件满足期间保持效果，条件失效后撤销。被动还可以使用层数、公式和信号组织更复杂的行为。

查阅参数时，可以先从[注册、定义与授予](foundation/registration.md)了解如何让单位获得被动，再查看[触发时机](events/triggers.md)、[一次性结果](actions/index.md)或[持续性结果](continuous/index.md)。
