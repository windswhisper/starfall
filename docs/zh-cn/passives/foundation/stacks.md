# 被动层数

[返回目录](../../index.md)

单位首次获得被动时，当前有效层数为 1。手动增加的层数单独记录；可叠加的乘客或重复科研来源也可以提供层数，首次提供的层数计入这一基础层，而非额外重复计算。有效总层数受上限约束。

## 可叠层的被动

```ini
[被动 ID 或结果节 ID]
Action=GrantPassive
; 向目标授予已注册的被动。

Action.Passive=(被动 ID)
; 要授予的被动。
; 必填。

Action.StackOnReapply=(布尔值)
; 目标已经拥有该被动时，再次授予是否增加一层手动层数。
; 默认值：no；首次获得被动时有效层数为 1。
```

弹头授予被动时，可使用 `Starfall.GrantPassives.StackOnReapply` 控制重复授予是否增加手动层数；字段及筛选规则见[弹头授予被动](warhead-grants.md)。

## 设置层数上限

```ini
[被动 ID]
Stack.Max=(正整数)
; 限制该被动的有效层数，包括手动层数和其他来源提供的层数。
; 默认值：2147483647。
```

## 增加或减少层数

```ini
[被动 ID 或结果节 ID]
Action=ChangePassiveStack
; 修改目标已经拥有的被动的手动层数。

Action.Passive=(被动 ID)
; 要修改层数的已注册被动。
; 必填；目标必须已拥有该被动。

Action.Amount=(非零有符号整数)
; 正数增加手动层数，负数减少手动层数。
; 必填。
```

普通被动的初始 1 层也可以扣除。减到 0 层或扣减量超过剩余层数时，目标失去该被动。科研或乘客提供的层数会保留；父被动仍有效时，关联子被动也会保留。

`StealPassive` 可以转移手动层数；普通被动的最后一层被转移时，来源单位会失去该被动。乘客支持来源提供的层数不能作为手动层数转移。

## 读取层数与生命周期

公式变量 `This.Stack` 表示当前执行的被动的有效层数。事件公式通常读取触发时的快照；持续状态公式读取当前有效层数。

多个来源提供同一个被动时，单位只执行一份该 ID 的被动。一个来源消失不一定使被动消失；失去最后一个来源后，相关层数和进度清除。`RemovePassive` 会清除该被动的层数及相关计数、等待状态；之后仍可通过有效来源重新获得。
