# 被动属性上下限

[返回目录](../../index.md)

`[Starfall.PassiveLimits]` 控制事件结果对单位属性产生的**累计值**的上下限。持续状态提供的倍率在累计值上继续相乘，最终结果可以超出这里的上下限。

各字段填写正整数百分比，可以省略 `%`；下限不得大于对应上限。无效值会使用默认值并写入 `Starfall.log`；如果默认下限大于上限，则按上限调整下限。

```ini
[Starfall.PassiveLimits]
Speed=(正整数百分比)
; 移动速度累计值的上限。
; 默认值：300%

Speed.Min=(正整数百分比)
; 移动速度累计值的下限。
; 默认值：1%

Firepower=(正整数百分比)
; 火力累计值的上限。
; 默认值：1000%

Firepower.Min=(正整数百分比)
; 火力累计值的下限。
; 默认值：1%

Armor=(正整数百分比)
; 装甲累计值的上限。
; 默认值：1000%

Armor.Min=(正整数百分比)
; 装甲累计值的下限。
; 默认值：1%

Scale=(正整数百分比)
; 单位体型累计值的上限。
; 默认值：300%

Scale.Min=(正整数百分比)
; 单位体型累计值的下限。
; 默认值：25%

ProjectileScale=(正整数百分比)
; 弹体体型及溅射范围累计值的上限。
; 默认值：300%

ProjectileScale.Min=(正整数百分比)
; 弹体体型及溅射范围累计值的下限。
; 默认值：1%

WeaponRange=(正整数百分比)
; 武器射程累计值的上限。
; 默认值：300%

WeaponRange.Min=(正整数百分比)
; 武器射程累计值的下限。
; 默认值：1%

FireRate=(正整数百分比)
; 射速累计值的上限。
; 默认值：300%

FireRate.Min=(正整数百分比)
; 射速累计值的下限。
; 默认值：1%
```

例如，`Firepower=200%` 将事件结果累计的火力限制在基础值的两倍；若同时存在 1.5 倍的持续火力效果，最终倍率可以达到 3 倍。
