# 被动动画与染色

[返回目录](../../index.md)

被动可在获得、触发或持续生效时显示动画，也可以为持有者染色。

```ini
[被动 ID]
Anim=(动画 ID)
; 在持有者身上播放跟随体型的循环动画。
; 默认值：无。

Anim.Always=(布尔值)
; yes 时附着动画忽略被动状态条件；仍受可见性和生命周期影响。
; 默认值：no；需要 Anim。

Anim.WhileReady=(布尔值)
; yes 时在事件被动冷却期间隐藏附着动画。
; 默认值：no；需要 Anim 和正数 Cooldown。

GainAnim=(动画 ID)
; 单位在地图上新获得被动时播放一次。
; 默认值：无。

TriggerAnim=(动画 ID)
; 通过触发检查后、执行结果前播放；持续状态在等待结束并进入状态时播放。
; 默认值：无。

TriggerAnim.Target=(Self 或 Target)
; 动画播放在持有者或事件对方处。
; 默认值：Self。

Tint.Color=(红,绿,蓝)
; 染色目标颜色，各分量为 0–255 的整数。
; 默认值：无。

Tint.Strength=(整数百分比)
; 原图向目标颜色混合的程度，范围 0%–100%。
; 默认值：50%；需要 Tint.Color。
```

动画 ID 必须已在游戏中注册。纯视觉被动在满足字段限制时可不写 `Trigger`；被动消失或单位离场时附着动画会移除或隐藏。多个染色效果以强度最大的为准，铁幕或力场护盾优先显示。
