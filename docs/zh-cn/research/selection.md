# 科研抽取与全局设置

[返回目录](../index.md)

本节配置科研总开关、点数发放、候选抽取和稀有度权重。普通购买固定消耗 100 点科研点；无效、阵营不符、前置未满足或不可重复获得的项目不会进入候选。

## 科研与点数

```ini
[Starfall.Research]
Enabled=(布尔值)
; 控制科研界面、点数发放、购买与免费科研奖励。
; 默认值：yes；关闭时已存储的点数和科研不会删除。

InitialPoints=(非负整数)
; 每位参与玩家的开局科研点。
; 默认值：0。

PeriodicPoints=(非负整数)
; 每个周期向参与玩家发放的科研点。
; 默认值：0；与 PeriodicIntervalSeconds 均为正数时生效。

PeriodicIntervalSeconds=(非负整数秒)
; 科研点周期发放的间隔，单位为游戏秒。
; 默认值：0；上限为 2147483647 除以 15 后向下取整。

AllowAIResearch=(布尔值)
; 允许电脑使用科研点并领取结果提供的免费科研选择。
; 默认值：no。

Repeatable=(布尔值)
; 科研项目是否默认允许重复获得。
; 默认值：no；可在单个项目节中覆盖。
```

## 候选与刷新

```ini
[Starfall.Research]
AllowCardRefresh=(布尔值)
; 允许普通科研卡片刷新。
; 默认值：yes；每个卡位每轮最多免费刷新一次。

MixedRarityPool=(布尔值)
; 将符合条件的不同稀有度项目混池，逐项按所属稀有度权重抽取。
; 默认值：no；yes 时优先于 SharedRaritySequence。

SharedRaritySequence=(布尔值)
; 使所有玩家按普通科研购买轮次共用稀有度随机序列。
; 默认值：no；免费科研和刷新不推进轮次。
```

默认抽取方式先按权重选一个有候选的稀有度，再从该档提供最多三个项目。刷新需要至少 100 科研点，但本身不扣点；没有合适候选时不消耗刷新次数。

共用稀有度序列只统一档位，不统一具体项目。如果指定档位没有可选项目，会从该玩家其他有候选且权重大于 0 的档位补选。混池模式下每个项目分别拥有其稀有度权重，同轮不会重复抽到同一项目。

## 稀有度权重

```ini
[Starfall.Research]
RarityWeight.Common=(非负整数)
; 普通项目的抽取权重。
; 默认值：5。

RarityWeight.Rare=(非负整数)
; 稀有项目的抽取权重。
; 默认值：4。

RarityWeight.Epic=(非负整数)
; 史诗项目的抽取权重。
; 默认值：1。

RarityWeight.Insane=(非负整数)
; 疯狂项目的抽取权重。
; 默认值：0。
```

权重为 0 的档位不参加普通抽取。指定稀有度的部分奖励有自己的筛选规则，详见[科研结果](effects.md)和[免费科研选择](free-choices.md)。
