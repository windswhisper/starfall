# 科研计数器

[返回目录](../index.md)

科研计数器属于获得该项目的玩家，供其单位共同读写。计数可以用于说明文案、被动公式和科研阶段条件。

```ini
[科研项目 ID]
Counters=(计数器名称列表)
; 声明本项目使用的玩家共享计数器。
; 默认值：无；项目 ID 和计数器名使用字母、数字或下划线，最长 127 字节。

Detail=(文本或文本 ID)
; 详细说明可通过公式读取已声明的科研计数器。
; 例如：所有步兵提升 $(Research.InfArmor.Level*10)% 的护甲
```

计数器初始值为 0，使用 `Research.项目ID.计数器名` 读取。项目未被玩家拥有时读取为 0，写入不会生效；项目被组合升级退役后，其计数器会移除。

```ini
[被动 ID 或结果节 ID]
Action=ChangeResearchCounter
; 修改事件所属玩家的科研计数器。

Action.Counter=(项目 ID.计数器名)
; 指定已声明的计数器。
; 必填；Action.Target 须为 Self。

Action.Amount=(非零有符号整数或公式)
; 增加或减少的数量。
; 必填；结果限制在 0–2147483647，公式结果向零截断。
```
