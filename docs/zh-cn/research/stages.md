# 科研阶段

[返回目录](../index.md)

科研阶段在玩家获得项目后检查条件；条件首次成立时执行该阶段的结果。一个项目可以拥有多个阶段。

```ini
[科研项目 ID]
Stages=(阶段 ID 列表)
; 指定属于该项目的阶段和检查顺序。
; 默认值：无。

[阶段 ID]
Condition.Formula=(科研公式)
; 非零时完成该阶段，公式可读取已声明的科研计数器。
; 例如：$(Research.SomeTask.Count>100)

Effect=(科研结果名称)
; 阶段完成时执行单个科研结果，专用参数写在本节。

Effects=(结果节 ID 列表)
; 阶段完成时按顺序执行多个结果节。
; 填写后使用结果列表而非本节单结果配置；列表不能为空。
```

阶段可使用[科研结果](effects.md)中的结果类型。每个玩家的阶段只完成一次，完成记录随存档保存；一次性结果在无有效目标时可能无法生效，且不会再次补发。
