# 免费与随机科研奖励

[返回目录](../index.md)

被动结果可以为目标所属玩家提供一次免费选择，或直接获得一个随机科研项目。这些奖励不消耗普通科研点，也不推进普通科研的共用稀有度序列。

## 免费选择

```ini
[被动 ID 或结果节 ID]
Action=GrantFreeResearch
; 向目标所属玩家提供一次免费科研选择。

Action.ResearchOptions=(科研项目 ID 列表)
; 限制可选项目范围。
; 默认值：不指定列表，从已注册项目中筛选。

Action.Rarity=(All、Common、Rare、Epic 或 Insane)
; 限制候选项目的稀有度。
; 默认值：All，不限制。
```

不指定列表时，按全局权重抽取最多三个不同项目；指定一至三个不同项目时按配置顺序提供，超过三个时按权重抽取。指定 `Action.Rarity` 时，即使该稀有度的全局权重为 0，也可以选择其中符合条件的项目。

免费选择仍检查玩家国家、前置、项目有效性和已有科研。没有合格候选时不会提供选择。多个免费机会可以等待领取，右上角科研按钮显示待领取数量。

## 直接获得随机科研

```ini
[被动 ID 或结果节 ID]
Action=GrantRandomResearch
; 向目标所属玩家立即授予一个随机科研项目。

Action.Rarity=(All、Common、Rare、Epic 或 Insane)
; 限制奖励项目的稀有度。
; 默认值：All，不限制。
```

该结果从符合条件的项目中随机选择，不使用普通科研的 `RarityWeight.*`。指定档位没有可用项目时不会回退到其他档位。免费选择或随机奖励作为**科研项目本身的结果**时，应使用[科研结果](effects.md)中的 `Effect` 和 `Reward.*` 字段，而不是这里的 `Action.*` 字段。
