# 科研羁绊

[返回目录](../index.md)

科研羁绊根据玩家拥有的成员项目数量激活对应档位。持续结果在满足门槛时生效；资金、转换等一次性奖励每位玩家每档只发放一次。

```ini
[Starfall.ResearchBondTypes]
0=(羁绊 ID)
; 注册科研羁绊。

[羁绊 ID]
Name=(文本或文本 ID)
; 羁绊显示名称。
; 默认值：羁绊 ID。

Members=(科研项目 ID 列表)
; 组成该羁绊的不同科研项目。
; 必填；项目须已注册。

Stages=(羁绊档位 ID 列表)
; 指定羁绊的奖励档位。
; 必填；至少需要一个有效档位。

[羁绊档位 ID]
RequiredCount=(正整数)
; 激活该档所需拥有的不同成员项目数量。
; 必填；不能超过不同成员项目的数量。

Summary=(文本或文本 ID)
; 覆盖该档自动生成的奖励说明。
; 默认值：自动生成；界面会自行显示数量门槛。

Effect=(科研结果名称)
; 达到门槛时生效的单个科研结果。

Effects=(结果节 ID 列表)
; 按顺序执行或提供多个科研结果。
; 填写后使用结果列表而非本节单结果配置；列表不能为空。
```

公式变量 `Bond.羁绊ID.Count` 可读取当前拥有的成员数量。门槛不再满足时会撤销该档持续效果，之后重新满足可恢复；一次性奖励不会重复发放。
