# 科研项目

[返回目录](../index.md)

科研项目需要注册并定义独立的配置节。普通科研每次消耗 100 点科研点，默认每个玩家只能获得同一项目一次；项目生效范围取决于其科研结果。

## 注册与通用参数

```ini
[Starfall.ResearchTypes]
0=(科研项目 ID)
; 注册科研项目。合并配置时使用未占用的非负整数编号。

[科研项目 ID]
Name=(文本或文本 ID)
; 卡片和已获得列表中显示的项目名称。
; 默认值：项目 ID；部分旧内置项目有专用默认值。

Summary=(文本或文本 ID)
; 科研卡片上显示的简短说明。
; 默认值：空；部分旧内置项目有专用默认值。

Detail=(文本或文本 ID)
; 悬停时显示的详细说明，可包含受支持的公式和占位符。
; 默认值：支持自动生成的结果会生成说明。

Detail.Decimals=(整数)
; Detail 中公式数值的固定小数位数。
; 范围：0–6；省略时最多显示两位并去除末尾零。

Icon=(图片路径)
; 科研图标，支持 PNG 或游戏可加载的 PCX。
; 默认值：内置备用图标。

TargetLabel=(文本或文本 ID)
; 卡片副标题中稀有度后面的作用对象名称。
; 默认值：根据结果及目标类型自动生成。

Rarity=(Common、Rare、Epic 或 Insane)
; 项目的稀有度，分别对应普通、稀有、史诗和疯狂。
; 默认值：Common；填写无效值会使项目不可用。

Effect=(科研结果名称)
; 指定该项目的单个结果，结果专用字段写在本节。
; 默认值：GrantPassive。

Effects=(结果节 ID 列表)
; 按顺序执行多个科研结果节；每个结果节必须分别设置 Effect。
; 默认值：不使用；填写后覆盖本节的单结果配置，不允许空列表。

Stages=(阶段 ID 列表)
; 指定该项目的计数或公式阶段，阶段字段写在对应阶段节中。
; 默认值：无；有效阶段存在时可以不配置获得项目时的结果。
```

结果种类及专用参数见[科研结果](effects.md)。`Effects` 中重复的结果节 ID 只执行首次出现的一次；任一结果配置无效可能使整个项目不可用。

## 获取条件

```ini
[科研项目 ID]
Countries=(国家 ID 列表或 *)
; 限制可以抽取或获得项目的国家；* 表示所有国家。
; 默认值：Countries 与 UnlockWithTech 均省略时不限制国家。

UnlockWithTech=(单位或建筑类型 ID 列表)
; 拥有其中任一类型的 UnlockTech 建造许可时，也可满足国家资格。
; 默认值：空；单独设置时要求拥有其中一项许可。

Prerequisites=(科研项目 ID 列表)
; 要求玩家已拥有列表中的所有前置科研。
; 默认值：无。

Excludes=(科研项目 ID 列表)
; 玩家已拥有任一列出项目时，排除此项目。
; 默认值：无；仅单向限制，双方互斥须分别配置。

Replaces=(科研项目 ID 列表)
; 获得本项目时退役列出的所有基础项目。
; 默认值：无；首次获得前必须拥有全部列出的项目。

Repeatable=(布尔值)
; 是否允许同一玩家重复获得该项目。
; 默认值：继承 [Starfall.Research] 的 Repeatable。

GrantOnly=(布尔值)
; yes 时只允许通过 Action=GrantResearch 指定授予。
; 默认值：no；普通抽取、免费选择和随机奖励均跳过此类项目。
```

`Replaces` 会停止基础项目的持续被动、价格和生产许可效果；已经发放的资金、单位转换等一次性结果不会撤销。项目引用无效的前置、形成循环，或依赖无效链时，会被排除。目标类型当前是否存在与国家、前置条件是分别判断的。
