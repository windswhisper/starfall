# 建筑免费科研

[返回目录](../index.md)

特殊建筑可以在被工程师成功占领或被间谍成功渗透后，向相应玩家提供一次免费科研选择。建筑仍须符合原版占领或渗透规则。

```ini
[建筑类型 ID]
Starfall.ResearchOptions=(科研项目 ID 列表)
; 指定此建筑提供的科研候选。
; 默认值：空；最多三个不同项目时按配置顺序显示。

Starfall.ResearchOptions.AllowEngineerCapture=(布尔值)
; 是否允许工程师成功占领后获得免费科研资格。
; 默认值：no。

Starfall.ResearchOptions.AllowSpyInfiltration=(布尔值)
; 是否允许间谍成功渗透后为间谍所属玩家提供资格。
; 默认值：no。
```

候选超过三个时按全局稀有度权重抽取最多三个不同项目；混池模式采用对应的混池规则。每个实体建筑只能领取一次，普通所属权转移不会替代合法占领或渗透。

玩家通过右上角科研按钮领取，角标显示待领取次数；领取免费科研不消耗科研点。建筑奖励不检查项目的国家和前置限制，但项目仍须有效、允许获得且至少有一个结果可生效。
