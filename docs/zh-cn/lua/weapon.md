# 武器开火脚本

[返回目录](../index.md)

武器开火脚本由选中的武器触发，无需注册被动。支持的武器接受一轮射击时执行一次回调，由脚本发射该轮所需的弹体。

```ini
[武器 ID]
Starfall.FireScript=(Lua 文件名)
; 指定武器开火时执行的脚本。
; 必填；地图可覆盖该字段。

Starfall.FireFunction=(函数名)
; 指定脚本导出的开火回调。
; 默认值：onFire；地图可覆盖该字段。
```

即使武器有多发连射，一轮射击也只排队一个回调；武器自身仍决定目标规则、整轮装填时间和一次弹药消耗。`ctx.self` 是开火者，`ctx.target` 是仍然存在的单位目标，`ctx.point` 保存开火时的目标格。

无效脚本或函数会记录配置错误并保留普通开火；已接受射击后的运行错误仍会消耗本轮射击。`Suicide`、`Spawner`、`LimboLaunch` 和 `DiskLaser` 等不支持此入口。

通过 Lua 的 `FireWeapon` 结果可使用可选的 `Origin` 指定本次发射位置。地图点的横向坐标以格为单位，可使用小数；`height` 表示相对地面或桥面的高度。也可使用存活且在地图上的单位句柄。指定的发射位置只影响本次开火，并优先于武器自身的发射位置设置。
