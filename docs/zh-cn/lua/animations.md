# Lua 可移动动画

[返回目录](../index.md)

Lua 可创建、移动和移除由当前上下文管理的动画。动画是视觉对象，不会自行造成伤害或移动单位。

| 方法 | 返回值 | 含义 |
| --- | --- | --- |
| `ctx:spawnAnim(id, point, options)` | 动画句柄整数或 `nil` | 在指定位置创建已注册动画；类型、资源或位置无效时返回 `nil`。 |
| `ctx:moveAnim(handle, point, frames)` | 布尔值 | 将动画设为在指定帧数内线性移动到目标位置，保留高度偏移。 |
| `ctx:removeAnim(handle)` | 布尔值 | 移除属于当前上下文的动画；句柄失效或不属于当前上下文时返回 `false`。 |

`spawnAnim` 的 `options` 支持以下区分大小写的字段：

| 字段 | 含义 | 默认值与约束 |
| --- | --- | --- |
| `loop` | 是否循环播放。 | `false`。 |
| `duration` | 动画存续帧数。 | `150`；整数 1–54000。 |
| `height` | 相对地面的高度偏移，单位为格。 | `0`；有限数值 -64–64。 |

动画目标点可使用小数格坐标；移动时长为 1–54000 帧。全局最多管理 2048 个 Lua 动画。普通单位移除时会清理其动画；动画的寿命和移动状态随存档保留。非循环原版动画可能在指定时长之前自然结束。
