# 状态、定时任务与同步随机

[返回目录](../index.md)

回调可以通过持久状态保存数据，安排后续帧的任务，并使用与其他玩家同步的随机数。

## 定时任务与状态

| 方法或字段 | 含义 |
| --- | --- |
| `ctx:schedule(frames, callbackName, data)` | 在指定正整数帧后执行已导出的回调，返回任务 ID；回调接收新的 `ctx` 和保存的 `data`。 |
| `ctx:cancel(id)` | 取消属于当前上下文的待执行任务；任务已执行、已取消或属于其他上下文时返回 `false`。 |
| `ctx.state` | 当前上下文的持久状态；键为 1–127 字节的字符串，赋值为 `nil` 时删除该键。 |
| `ctx.taskId` | 当前回调由定时任务触发时的任务 ID。 |

可保存 `nil`、布尔值、整数、有限小数、字符串、单位句柄及由整数或字符串键构成的普通表。不支持函数、循环引用、元表或其他 userdata；单个数据树最多 256 个节点、深度 12，字符串与键合计最多 8 KiB。

从 `ctx.state` 读取表时得到的是副本；修改副本后须重新赋值才能保存。普通状态按持有者和技能区分；超武及地图上下文按调用区分，同一次调用中的步骤共享状态。

同一任务存储中，相同帧到期的任务按创建顺序执行。普通单位被移除时其任务和状态会清理；只失去技能通常不会取消已排队任务。延迟回调读取当前对象和参数，若需要原始事件数据，应存入 `data`。

## 同步随机

| 方法 | 含义 |
| --- | --- |
| `ctx:randomInt(min, max)` | 从闭区间随机取整数；参数须为有序的 32 位有符号整数。 |
| `ctx:randomPoint(area)` | 在地图可用范围内的圆形区域中均匀选择地图格；区域包含整数中心格和 0–128 格半径。 |

流火随机流会同步并随存档保存，与原版武器随机流独立。普通单位与序列／地图分别有任务和状态容量，详细上限见[运行环境与限制](limits.md)。
