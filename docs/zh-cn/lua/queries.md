# 玩家与附近单位查询

[返回目录](../index.md)

Lua 可读取玩家状态快照，并按地图位置或单位周围的范围查找当前单位。

## 玩家快照

| 方法 | 返回值 | 含义 |
| --- | --- | --- |
| `ctx:house(index)` | 玩家快照表或 `nil` | 读取指定玩家；省略索引时读取持有者或本次调用所属玩家。 |

玩家快照字段包括 `index`、`powerOutput`、`powerDrain`、`powerBalance`、`credits` 和 `researchPoints`。快照是读取时的副本；修改返回表不会改变玩家状态，需要更新数据时应重新查询。

## 附近单位

| 方法 | 返回值 | 含义 |
| --- | --- | --- |
| `ctx:nearbyUnits(center, radius, filters)` | 单位句柄数组 | 在单位或整数地图坐标周围查找单位；半径为 0–128 格，结果按对象 ID 排序。 |

`filters` 使用以下区分大小写的键：

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `houses` | 所属关系列表；关系相对执行上下文的所属玩家。 | `All` |
| `types` | 具体类型 ID 或科研分类选择器。 | `*` |
| `includeSelf` | 中心为单位时，是否包含该中心单位。 | `false` |
| `visibleOnly` | 是否排除无法被所属方侦测的敌方隐形或伪装单位。 | `false` |

`houses` 和 `types` 支持逗号分隔的字符串或字符串数组。`visibleOnly` 使用同步的侦测状态，不表示本地视野或迷雾是否显示。
