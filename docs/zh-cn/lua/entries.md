# Lua 脚本入口

[返回目录](../index.md)

不同脚本入口对应不同的触发时机和上下文。脚本文件须放在游戏目录，返回包含回调函数的 Lua 表。

| 入口 | 配置方式 | 触发时机 |
| --- | --- | --- |
| 被动事件 | 在被动中配置 `Action=RunScript`。 | 按被动的 `Trigger` 执行。 |
| 主动技能 | 在主动技能中配置 `Action=RunScript`。 | 玩家释放技能时执行。 |
| 武器开火 | 在武器上设置 `Starfall.FireScript`。 | 支持的武器接受一轮射击时执行。 |
| 弹头引爆 | 在弹头上设置 `Starfall.DetonateScript`。 | 弹头在地图上引爆并结算伤害后执行。 |
| 地图触发 | 注册[地图 Lua 预设](../map/lua-presets.md)，使用地图动作 `9602`。 | 对应地图触发动作执行时。 |
| 自定义超武 | 在 ActionSequence 的结果步骤中配置 `RunScript`。 | 对应超武步骤执行时。 |
| 抛射体运动 | 在抛射体上设置 `ProjectileScript`。 | 发射、飞行更新及移动路径回调。 |

## 被动与主动技能脚本

```ini
[被动或主动技能 ID]
Action=RunScript
; 调用指定 Lua 回调。

Action.Script=(Lua 文件名)
; 指定脚本文件。
; 必填；省略 .lua 时自动补全。

Action.Function=(函数名)
; 指定脚本返回表中的回调函数。
; 必填。

Script.Param.参数名=(数值或文本)
; 向脚本传递自定义参数。
; 可配置多个参数；回调中通过 ctx.params 的小写参数名读取。
```

主动技能的目标与结果限制见[主动技能结果](../active/results.md)。普通被动脚本的 `ctx.self` 和 `ctx.target` 取决于触发事件；伤害拦截回调的动作限制与普通事件不同。

## 文件与参数

流火使用 Lua 5.4.8。脚本使用 UTF-8 编码，每个文件最大 1 MiB。INI 配置的函数名查找不区分大小写，但仅大小写不同的重名函数会产生歧义；延迟任务填写的回调名须与返回表中的函数名完全一致。

`Script.Param.*` 的数值字符串会转换成 Lua 数字；其他值作为保留大小写的字符串。每次回调都会重新初始化模块变量；需要跨回调保存的数据应使用[状态与定时任务](timers.md)，不要依赖模块局部变量。
