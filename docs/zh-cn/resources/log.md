# Starfall.log 日志

[返回目录](../index.md)

`Starfall.log` 是流火的诊断日志，位于游戏目录中。遇到配置不生效、技能未出现或 Lua 脚本异常时，可以先查看这个文件。

## 日志内容

- **配置问题**：无效的字段、数值或组合，以及未注册的被动、单位类型和其他引用。
- **科研问题**：可能包含项目节、字段、数值和错误原因；能确定来源时也会记录文件行号。
- **Lua 问题**：脚本加载或执行错误，以及相关文件、回调函数和错误位置。
- **资源问题**：部分图像、音效或曳光样式缺失及配置无效信息。

日志通常以追加方式写入，文件中可能包含之前运行留下的信息。检查时应结合最近一次运行的记录及对应配置；合并规则中的问题不一定能定位到原始文件或具体行号。被动配置无效时，依赖它的科研或授予预设也可能无法使用。

日志用于辅助定位问题，并不保证记录所有游戏异常。Lua 的配置和运行限制见 [Lua 脚本入口](../lua/entries.md)与 [Lua 运行环境与限制](../lua/limits.md)。
