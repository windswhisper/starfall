StarfallLab 流火实验室

面向模组制作者的规则和接口参考。选择功能入口查看简介与参数，完整目录位于页面左侧。

主要功能

被动能力→为单位配置事件触发或持续生效的能力，组合条件、结果、层数和公式。主动技能→配置由玩家操作释放的技能，设置目标、冷却、图标和指示器。科研三选一→创建可供玩家选择的科研项目，配置稀有度、获取条件和升级奖励。Lua 脚本→通过脚本查询游戏状态、执行结果、安排定时任务并扩展自定义行为。
基础配置

通用类型、单位与数值约定

本节说明配置中常见的数据类型、计量单位和术语，便于理解各参数的填写要求。

INI 参数的配置位置

词典中的 INI 参数表默认写在游戏加载的 rulesmd.ini 规则中。需要写在 artmd.ini、地图文件或其他位置的参数，会在对应参数表附近特别标注。部分流火配置也支持写入 Starfall.ini；是否支持及读取优先级以对应功能的说明为准。

通用类型与单位

  • ID：被动、科研、结果等对象使用的标识符。引用时填写 ID，而不是显示名称；合并配置时应使用不冲突的 ID。
  • 布尔值：除字段另有说明外，使用 yes 或 no。不能假定所有字段都接受 true 或 1。
  • 列表：通常用英文逗号分隔。是否保留重复项取决于具体字段，例如被动的 Actions 保留重复执行步骤。
  • 百分比与倍率：按字段要求填写。例如 +25% 表示增加 25%，1.25 表示 1.25 倍；两种格式不能随意互换。
  • 格：地图坐标单位，不是屏幕像素。整数坐标还须位于可游玩地图内。
  • 帧与游戏秒：帧指模拟帧；按游戏秒配置的流火设置以 15 帧为一游戏秒，实际经过时间受游戏速度影响。
  • 玩家（House）：游戏中拥有单位或科研的玩家实例，与出生点编号不是同一概念。
  • 配置注释：INI 使用分号 ; 引出注释，不要依赖字符串中的分号被保留。

单位类型、武器、弹头和动画等原版对象 ID 必须在当前规则中存在。不同功能的参数、默认值和限制以各自章节为准。

被动能力

被动能力简介

被动能力用于给单位或建筑添加自动生效的规则。单位可以自带被动，也可以通过科研、弹头或其他效果获得被动。

事件型被动在指定时机检查条件，然后执行结果；持续型被动在条件满足期间保持效果，条件失效后撤销。被动还可以使用层数、公式和信号组织更复杂的行为。

查阅参数时，可以先从注册、定义与授予了解如何让单位获得被动，再查看触发时机、一次性结果或持续性结果。

被动能力 / 注册与来源

注册、定义与授予

被动先注册，再授予单位。注册本身不会使单位获得该能力。事件型被动可执行一次性结果；持续型被动使用 Trigger=WhileState 和 Modifier.*。

单位还可通过科研、弹头和其他结果获得被动。

合并到已有配置时，保留原有注册项，并把新 ID 追加到单位已有的 Starfall.Passives 列表。

被动能力 / 注册与来源

弹头授予被动

弹头可以在命中符合条件的单位时授予被动，并按所属关系和单位类型筛选。

CellSpread=0 仅向直接命中的单位授予；正范围按爆炸位置筛选。零伤害命中也可授予，但死亡、离场、铁幕保护和弹头对应装甲 Verses 为零的目标会被排除。同一次引爆对同一单位的每项被动最多授予一次。

被动能力 / 注册与来源

被动来源

被动可由多个来源共同提供，仍按同一个被动 ID 识别。不同来源提供的同名被动默认不会叠加执行或重复计算效果，单位只持有一份该被动。明确配置重复授予叠层、可叠层乘客或可重复科研时，可以增加被动的有效层数。

失去一个来源不一定失去能力；彻底失去后再次获得才会重新触发 OnPassiveGained。层数的配置与增减见被动层数。

被动能力 / 注册与来源

被动层数

单位首次获得被动时，当前有效层数为 1。手动增加的层数单独记录；可叠加的乘客或重复科研来源也可以提供层数，首次提供的层数计入这一基础层，而非额外重复计算。有效总层数受上限约束。

可叠层的被动

弹头授予被动时，可使用 Starfall.GrantPassives.StackOnReapply 控制重复授予是否增加手动层数；字段及筛选规则见弹头授予被动。

设置层数上限

增加或减少层数

普通被动的初始 1 层也可以扣除。减到 0 层或扣减量超过剩余层数时，目标失去该被动。科研或乘客提供的层数会保留；父被动仍有效时，关联子被动也会保留。

StealPassive 可以转移手动层数；普通被动的最后一层被转移时，来源单位会失去该被动。乘客支持来源提供的层数不能作为手动层数转移。

读取层数与生命周期

公式变量 This.Stack 表示当前执行的被动的有效层数。事件公式通常读取触发时的快照；持续状态公式读取当前有效层数。

多个来源提供同一个被动时，单位只执行一份该 ID 的被动。一个来源消失不一定使被动消失；失去最后一个来源后，相关层数和进度清除。RemovePassive 会清除该被动的层数及相关计数、等待状态；之后仍可通过有效来源重新获得。

被动能力 / 一次性结果

多结果

多结果让一次触发按指定顺序执行多个结果，适合组合多种效果。

同一被动中，Actions 不能与 Action 或 RandomActions 同时使用。

每个结果节只填写一个 Action 及其对应的 Action.* 参数，不支持嵌套结果列表。多个结果共用一次计数、概率和冷却判定，至少一个结果成功即可触发冷却。已执行的结果不会回滚；部分结果失败会停止后续步骤，具体限制以该结果的说明为准。

普通事件的公式通常使用事件触发时的快照，前一个结果不会改写原始快照。

被动能力 / 一次性结果

随机结果

随机结果从指定结果列表中按权重抽取并执行，适合制作随机奖励。

同一被动中，RandomActions 不能与 Action 或 Actions 同时使用。

抽中的结果执行失败时不重新抽取。至少一个结果成功即可触发冷却。

被动能力 / 一次性结果

强制位移

强制位移可推开、拉近或击飞目标，并可设置移动距离、高度及碰撞规则。

水平位移或高度至少有一项有效且非零。位移过程更新实际水平坐标；高度达到阈值后使用防空目标规则，下降到阈值以下恢复地面目标。忽略碰撞时落地可能碾压单位，撞到建筑或落在不可通行地形也可能导致死亡。

被动能力 / 一次性结果

超时空传送

超时空传送将符合条件的地面移动单位送到目标附近的可用格子。

例如，载具受伤后传送到攻击者附近。

即时传送保留单位身份、生命和效果，但会清除现有移动和命令。不要在同步伤害拦截内直接传送，应延后执行。

被动能力 / 一次性结果

载具跳跃

类似镰刀机甲的跳跃移动，建议配合主动技能发动。

载具跳跃落地时会发动单位原生的碾压能力，可以摧毁目标点的步兵或载具，若目标格被占据又无法碾压时会改为寻找附近空地着陆。

作为主动技能使用时，目标类型须为 Point，跳跃距离由 Active.Range 配置；不应在主动技能节中填写 Action.Destination 或 Action.Jump.Range。

弹射乘客

类似牛蛙战车的载员弹射，建议配合主动技能发动。

弹射单位

作为主动技能使用的乘客弹射须选择 Point 目标，弹射距离由 Active.Range 配置；不应在主动技能节中填写 Action.Destination、Action.Eject.Range。EjectUnit 不属于主动技能可直接配置的结果。

被动能力 / 一次性结果

挂载子单位

AttachUnit 在存活且位于地图上的步兵、载具、飞机或建筑上创建一个真实的步兵或载具子单位。每次成功执行创建一个，子单位不能继续挂载子单位。

子单位跟随母体位置、朝向和所属方，保留自己的原生类型被动。母体销毁时子单位移除；子单位销毁后槽位释放。同占地建筑变形保留挂载单位及偏移。

移除挂载单位

没有匹配项时结果失败，并停止当前有序 Actions 或 Lua ctx:actions 列表；此前已执行的结果不会回滚。

自定义信号

信号不需要注册。发送后排队交付，接收被动使用 Trigger=OnSignal 和匹配的 Signal。

发送方

接收方

接收时 Self 是接收者，Target 是附带单位，Sender 是发送者；Filter.Target* 筛选附带单位。信号链接收深度最多 16 层，最多交付 1024 次，超限会停止并记录日志。

被动能力 / 持续性结果

持续效果概述

这些字段用于 Trigger=WhileState。条件成立时生效，条件不再成立时撤销。未填写的倍率默认为 1，开关默认不产生效果。不同持续被动的倍率相乘；事件结果改变的累计值另行计算。

被动能力 / 持续性结果

属性倍率

持续属性倍率在状态满足时调整单位或建筑的属性，状态失效后撤销。

以下参数用于 Trigger=WhileState 的被动；未填写的倍率默认为 1，开关默认不产生效果。

被动能力 / 持续性结果

被动属性上下限

[Starfall.PassiveLimits] 控制事件结果对单位属性产生的累计值的上下限。持续状态提供的倍率在累计值上继续相乘，最终结果可以超出这里的上下限。

各字段填写正整数百分比，可以省略 %；下限不得大于对应上限。无效值会使用默认值并写入 Starfall.log；如果默认下限大于上限，则按上限调整下限。

例如，Firepower=200% 将事件结果累计的火力限制在基础值的两倍；若同时存在 1.5 倍的持续火力效果，最终倍率可以达到 3 倍。

公式语法与规则

公式使用 $(...) 包裹，不是 Lua。比较运算结果为 0 或 1；小数和百分比字面量均可使用，例如 1.5% 等于 0.015。

主动技能

主动技能简介

主动技能由玩家选中单位后操作释放，可设置无目标、选取单位、地图点、区域或方向等目标方式。

技能可以通过单位类型绑定、科研或其他效果授予。技能具有独立的目标规则和冷却，也可以配置按钮图标、名称与目标指示器。

查阅参数时，可以从注册与授予开始，再按需要查看目标与释放方式、冷却及技能结果。

主动技能 / 基础配置

主动技能注册与授予

主动技能由玩家选择单位后使用，与被动共用注册表和授予方式。注册只定义技能，单位还须通过类型绑定、科研或其他授予方式获得该技能。

技能也可通过科研的 GrantPassive 结果或其他被动的授予结果获得。同一技能 ID 在混合选择中共用一个界面按钮；每个单位的冷却分别计算。

主动技能不支持普通被动的筛选条件、Chance、Actions、持续状态条件或 Stack.Max。释放时使用单个受支持的结果，具体见技能结果与脚本。

主动技能 / 基础配置

目标选择与释放方式

主动技能可以无目标释放，或由玩家选择单位、地图位置、区域或方向。目标类型决定可填写的范围和筛选字段。

释放者必须属于发出命令的玩家、拥有该技能、存活且位于地图上，并处于允许操作的状态。单位目标仍受隐形和伪装的可见性规则限制；方向目标不能与施法者位于同一格，超出地图边界时终点会缩短。

JumpTo 和 EjectPassengers 需要 Point 目标和大于 0 的 Active.Range；省略时分别使用 6 格和 8 格。ActSp 的 StartUnitOrder 要求 Area，CancelUnitOrder 要求 None。

主动技能 / 基础配置

主动技能冷却

冷却按每个技能持有者分别计算，在技能成功生效后开始。界面以游戏秒显示剩余时间并向上取整。

多个选中单位共用按钮时，只要其中一个持有者可以释放，就不显示倒计时；否则显示最短的剩余冷却。成功执行原生结果、改变持久状态或安排任务可以使脚本释放成功，Lua 仅返回 true 本身不会启动冷却。

Active.InterruptOrders=yes 在施法者和目标通过检查后、结果执行前中断命令；即使脚本最终没有产生有效结果，也可能已经中断命令。

主动技能 / 界面与效果

主动技能名称与图标

技能名称和图标用于选中持有者后显示的按钮，不改变技能的实际效果或目标规则。

PNG 图标支持透明通道；图片本身的不透明黑色像素不会自动变透明。图标绘制会裁切到按钮开口，重要图案应尽量放在图片中间。

主动技能 / 界面与效果

主动技能目标指示器

目标指示器显示技能的施法范围、目标位置和方向。贴图只影响本地显示，不改变有效射程或实际命中范围。

指示器使用透明 PNG 原图；范围圈和准星按地面视角投影到游戏画面。方向箭头分为头、中、尾三段，改变长度时只拉伸中段。有效目标显示亮蓝色，无效目标显示红色；范围圈自转，目标准星循环缩放。

游戏目录中的 sfindicator_ring.png、sfindicator_target.png 和 sfindicator_arrow.png 可覆盖内置默认图；单个技能也可通过上述字段单独指定。自定义图片缺失时回退内置图。

主动技能 / 界面与效果

主动技能结果

主动技能一次只配置一个受支持的结果。脚本技能使用 RunScript；原生载具跳跃、乘客弹射和 ActSp 持续指令有各自的目标要求。

Lua 脚本结果

脚本通过 ctx.self 访问施法者；单位目标通过 ctx.target 访问，点目标通过 ctx.point 访问。区域目标提供 ctx.area，方向目标提供 ctx.direction 和终点 ctx.point。延迟任务若需使用原始目标数据，应将需要的数据保存到任务参数中。

其他受支持的结果

这些 Action 是互斥选项。StartUnitOrder 必须指定已注册的 Action.Order，CancelUnitOrder 可选填 Action.Order 限制取消的指令。跳跃和弹射的范围通过 Active.Range 配置；其他可用参数见载具跳跃和弹射乘客与单位。

主动技能只能直接配置上面列出的受支持结果，不支持直接配置其他一次性结果或多结果列表。其他效果可通过 Lua 结果调用执行。

科研三选一

科研三选一简介

科研三选一是一套面向玩家的升级规则：玩家积累科研点后，可以从当前提供的候选项目中选择一项。项目的稀有度、获取条件和具体效果均可配置。

科研可以授予被动、修改价格、解锁建造或提供其他奖励。除普通购买外，地图和特殊效果也可以提供免费选择或随机科研；具体获取方式遵循各自的筛选规则。

查阅参数时，可以先看科研项目与科研结果，再按需要查看抽取与全局设置和建筑免费科研。

科研三选一 / 项目与结果

科研项目

科研项目需要注册并定义独立的配置节。普通科研每次消耗 100 点科研点，默认每个玩家只能获得同一项目一次；项目生效范围取决于其科研结果。

注册与通用参数

结果种类及专用参数见科研结果。Effects 中重复的结果节 ID 只执行首次出现的一次；任一结果配置无效可能使整个项目不可用。

获取条件

Replaces 会停止基础项目的持续被动、价格和生产许可效果；已经发放的资金、单位转换等一次性结果不会撤销。项目引用无效的前置、形成循环，或依赖无效链时，会被排除。目标类型当前是否存在与国家、前置条件是分别判断的。

科研三选一 / 抽取与奖励

科研抽取与全局设置

本节配置科研总开关、点数发放、候选抽取和稀有度权重。普通购买固定消耗 100 点科研点；无效、阵营不符、前置未满足或不可重复获得的项目不会进入候选。

科研与点数

候选与刷新

默认抽取方式先按权重选一个有候选的稀有度，再从该档提供最多三个项目。刷新需要至少 100 科研点，但本身不扣点；没有合适候选时不消耗刷新次数。

共用稀有度序列只统一档位，不统一具体项目。如果指定档位没有可选项目，会从该玩家其他有候选且权重大于 0 的档位补选。混池模式下每个项目分别拥有其稀有度权重，同轮不会重复抽到同一项目。

稀有度权重

权重为 0 的档位不参加普通抽取。指定稀有度的部分奖励有自己的筛选规则，详见科研结果和免费科研选择。

科研三选一 / 抽取与奖励

免费与随机科研奖励

被动结果可以为目标所属玩家提供一次免费选择，或直接获得一个随机科研项目。这些奖励不消耗普通科研点，也不推进普通科研的共用稀有度序列。

免费选择

不指定列表时，按全局权重抽取最多三个不同项目；指定一至三个不同项目时按配置顺序提供，超过三个时按权重抽取。指定 Action.Rarity 时，即使该稀有度的全局权重为 0，也可以选择其中符合条件的项目。

免费选择仍检查玩家国家、前置、项目有效性和已有科研。没有合格候选时不会提供选择。多个免费机会可以等待领取，右上角科研按钮显示待领取数量。

直接获得随机科研

该结果从符合条件的项目中随机选择，不使用普通科研的 RarityWeight.*。指定档位没有可用项目时不会回退到其他档位。免费选择或随机奖励作为科研项目本身的结果时，应使用科研结果中的 Effect 和 Reward.* 字段，而不是这里的 Action.* 字段。

科研计数器

科研计数器属于获得该项目的玩家，供其单位共同读写。计数可以用于说明文案、被动公式和科研阶段条件。

科研阶段

科研阶段在玩家获得项目后检查条件；条件首次成立时执行该阶段的结果。一个项目可以拥有多个阶段。

科研羁绊

科研羁绊根据玩家拥有的成员项目数量激活对应档位。持续结果在满足门槛时生效；资金、转换等一次性奖励每位玩家每档只发放一次。

建筑定时产出科研点

科研三选一 / 建筑科研

建筑免费科研

特殊建筑可以在被工程师成功占领或被间谍成功渗透后，向相应玩家提供一次免费科研选择。建筑仍须符合原版占领或渗透规则。

候选超过三个时按全局稀有度权重抽取最多三个不同项目；混池模式采用对应的混池规则。每个实体建筑只能领取一次，普通所属权转移不会替代合法占领或渗透。

玩家通过右上角科研按钮领取，角标显示待领取次数；领取免费科研不消耗科研点。建筑奖励不检查项目的国家和前置限制，但项目仍须有效、允许获得且至少有一个结果可生效。

被动与主动技能脚本

主动技能的目标与结果限制见主动技能结果。普通被动脚本的 ctx.self 和 ctx.target 取决于触发事件；伤害拦截回调的动作限制与普通事件不同。

文件与参数

流火使用 Lua 5.4.8。脚本使用 UTF-8 编码，每个文件最大 1 MiB。INI 配置的函数名查找不区分大小写，但仅大小写不同的重名函数会产生歧义；延迟任务填写的回调名须与返回表中的函数名完全一致。

Script.Param.* 的数值字符串会转换成 Lua 数字；其他值作为保留大小写的字符串。每次回调都会重新初始化模块变量；需要跨回调保存的数据应使用状态与定时任务，不要依赖模块局部变量。

Lua 脚本 / 脚本入口

武器开火脚本

武器开火脚本由选中的武器触发，无需注册被动。支持的武器接受一轮射击时执行一次回调，由脚本发射该轮所需的弹体。

即使武器有多发连射，一轮射击也只排队一个回调；武器自身仍决定目标规则、整轮装填时间和一次弹药消耗。ctx.self 是开火者，ctx.target 是仍然存在的单位目标，ctx.point 保存开火时的目标格。

无效脚本或函数会记录配置错误并保留普通开火；已接受射击后的运行错误仍会消耗本轮射击。Suicide、Spawner、LimboLaunch 和 DiskLaser 等不支持此入口。

通过 Lua 的 FireWeapon 结果可使用可选的 Origin 指定本次发射位置。地图点的横向坐标以格为单位，可使用小数；height 表示相对地面或桥面的高度。也可使用存活且在地图上的单位句柄。指定的发射位置只影响本次开火，并优先于武器自身的发射位置设置。

Lua 脚本 / 脚本入口

弹头引爆脚本

弹头引爆脚本在每次地图上的弹头引爆完成伤害结算后执行，空地引爆也会触发。

回调中的 ctx.warhead 是弹头 ID，ctx.point 是引爆格，ctx.damage 是经过目标装甲计算前的基础伤害；ctx.owner 为开火所属方索引，无归属时使用中立方。ctx.self 和 ctx.target 初始为空。

一次直接命中及其范围伤害共用一次回调；独立引爆各自执行。回调同步引爆自身弹头时会执行爆炸，但阻止同一回调递归进入。

Lua 结果调用

Lua 可以直接执行流火结果、按顺序执行结果列表，或引用已有的 INI 单结果节。各入口仍受其上下文限制。

方法返回值含义
ctx:action(name, args)布尔值执行一个指定名称的流火结果。
ctx:actions(list)布尔值按数组顺序执行多个结果；至少一个成功时返回真。

地图与小队 / 预设与单位绑定

被动授予预设

被动授予预设将被动列表、持续时间和接收类型组合起来，供地图触发动作和小队脚本动作 9601 使用。

配置位置：rulesmd.ini 或 Starfall.ini。

预设只作用于执行时存活、在地图上且状态允许的对象；满足条件的建筑也可以接收。不填写 TargetTypes 时不会为后续出生的单位自动补发。

地图与小队 / 预设与单位绑定

地图 Lua 预设

地图 Lua 预设把动作编号 9602 的数值参数关联到 Lua 脚本和回调函数。Lua 回调所属玩家由地图触发动作的参数 4 指定。

配置位置：rulesmd.ini、Starfall.ini，或地图文件（.map）中的对应节。

回调可读取 ctx.owner；触发关联的对象可用时提供 ctx.self，有效触发位置可用时提供 ctx.point。回调开始时没有 ctx.target。延迟任务不依赖关联单位存活，但之后访问该单位前仍应检查其有效性。

Lua 接口见上下文与事件数据和结果调用。地图回调遵循序列上下文的结果限制，不能直接假定所有普通被动目标都存在。

地图与小队 / 预设与单位绑定

地图单位被动绑定

地图可以为某一单位或建筑类型追加被动或主动技能绑定，而不改变该地图以外的类型配置。

配置位置：地图文件（.map）中的单位或建筑类型节。

地图绑定与已有的类型绑定合并，同名 ID 不会重复添加。绑定作用于该地图上的类型，不是单独指定某一个地图对象；地图绑定会随存档保留。

特殊行为 / 单位与建筑

子机与地面守卫

子机行为扩展原版飞行器子机的警戒、跟随和绕行；建筑也可以单独管理一个使用普通地面移动方式的守卫。飞行子机仍使用原版子机槽位。

子机行为

飞行子机需要原版子机槽位；没有攻击目标时主动起飞，需要母体当前使用的发射武器配置 Spawner=yes。母体指定的目标优先；飞行子机弹药耗尽后使用原版返航和补给。

建筑地面守卫

地面守卫使用自身寻路和武器，每个建筑管理一个；出口没有空位时等待。建筑被占领时，旧守卫归原玩家，新所属方在等待后补充守卫；建筑销毁或出售后存活守卫变为普通单位。

警戒格与停靠

可用建筑集合点或 Lua 的 unit:setDroneGuardCell(point) 设置警戒格，后一次设置覆盖前一次。地面守卫应选择可到达的格子；警戒格和守卫状态随存档保留。

启用建筑停靠时，飞行子机须满足建筑停机位及飞机 Dock 等原版要求。地面守卫向建筑地基附近设置集合点可召回停靠；向更远处设置集合点可派出警戒。

特殊行为 / 单位与建筑

高级驻军

高级驻军让建筑内的步兵使用各自可在运输中使用的武器向外开火，并分别装填。全局启用后，可以按建筑类型覆盖开关及倍率。

驻军武器遵循 OpenTransportWeapon、FireInTransport 等原有配置。手动攻击的可选目标由当前最早进入的驻军武器决定；各驻军优先攻击可攻击的指定目标，否则按自身武器规则索敌。可手动攻击符合武器条件的中立对象，按住 Ctrl 可对可攻击的空地强制开火。

特殊行为 / 单位与建筑

建筑高台

建筑高台为高于周围地面的建筑平台，可承载地面单位和普通建筑。新配置使用完整矩形外围地基，中间留空作为台面。

高台的地基参数写在 artmd.ini 对应的建筑图像节中：Foundation=Custom，Foundation.X 和 Foundation.Y 指定外部宽度与长度，两个尺寸均至少为 3；Foundation.n 列出完整的一格宽外围，内部留空。台面抬高四级地形高度；外围与台面必须平坦、同高且满足地形和占用检查。

单位可从高台外围进入空闲台面；选择高台并部署可让台面单位下来。出售或摧毁高台会恢复原地形，同时摧毁台面上的建筑并使地面单位坠落死亡。高台图像可在 artmd.ini 配置 CanHideThings=no，以避免遮住台面单位。

特殊行为 / 单位与建筑

移动建造节点

移动建造节点让指定步兵、载具或符合条件的旋翼飞机在当前位置提供建造范围，节点随单位移动。

建筑仍使用自身的 Adjacent 和原版地基、地形检查。被运输、驻军或处于坠落状态的单位不提供节点；空中 Jumpjet、Hover 单位及旋翼飞机使用其正下方的地图格。

特殊行为 / 单位与建筑

实体围墙

实体围墙使用真实建筑作为端点和连接段；同所属方、同分组且位于同一高度的端点可沿地图轴连接。

实体围墙使用建筑类型而非原版覆盖物围墙；类型需设置 Wall=no。使用 BaseNormal=no 可避免围墙扩展普通建造范围。各段独立承受伤害，连接路径受阻时不会在受阻方向生成围墙段。

特殊行为 / 单位与建筑

持续单位指令

持续单位指令使单位按照选定区域持续执行攻击或自动进入行为，可由命令栏、主动技能或 Lua 启动。

区域打击

区域打击让单位留在当前位置，持续搜索并攻击指定圆形区域内的合格目标。目标还须位于单位当前武器射程内；每个单位独立选择目标，一轮连发期间会保持同一合格目标。区域内暂时没有目标时，指令仍会等待并继续搜索。

选择新区域会替换之前的打击区域；对单位下达移动、攻击、停止或部署等手动指令可接管单位。

自动进驻

自动进驻让步兵或载具在指定圆形区域内寻找最近的合适容器，并为单位分配可用位置。容器可配置为运输工具、驻军建筑或坦克碉堡；实际能否进入仍取决于单位类型、所属关系和剩余空间。

一次指令只分配当时可用的位置，没有分到位置的单位会原地转入警戒。前往途中如果目标失效，或单位连续 180 帧没有移动进展，也会返回警戒；手动移动或停止可取消前往。之后出现空位时，需要重新下达指令。

注册与参数

移动、攻击、停止或部署等手动指令可以接管单位。指令随存档保留，单位死亡或所属方改变时结束。Lua 方法见Lua 单位指令。

特殊行为 / 武器与抛射体

建筑拦截抛射体

建筑和实体围墙可按地基及指定高度拦截飞行中的实体抛射体。低弹道可能击中建筑侧面，高弹道可以越过顶部。

接触时使用弹体原有弹头在碰撞位置引爆，并以建筑作为目标。瞬时抛射体、激光和电弧不使用此飞行碰撞检查。实体围墙的索敌限制仍由 EntityWall.BlocksProjectiles 和 EntityWall.HighWall 控制。

特殊行为 / 武器与抛射体

Lua 抛射体路径

可见实体抛射体可以由 Lua 按帧控制速度、位置和转向，并在飞行路径上执行支持的结果。该功能也可与穿透抛射体一起使用。

配置字段、回调和 p 上下文接口见Lua 抛射体运动；穿透范围和伤害参数见穿透抛射体。

特殊行为 / 武器与抛射体

穿透抛射体

穿透抛射体沿飞行路径检测多个合格对象，每发弹体对同一对象最多直接命中一次。可结合 Lua 抛射体脚本控制路径。

首个有效命中使用完整伤害，之后按衰减和下限计算；每个目标仍单独应用装甲。飞行结束默认没有结束爆炸；配置结束弹头后使用剩余伤害。脚本路径接口见Lua 抛射体运动。

特殊行为 / 武器与抛射体

相对目标的武器发射位置

武器可以从目标位置附近发射，而不是从开火单位的武器出口发射。该设置不改变原有射程检查、归属或目标跟踪。

目标为地面时使用目标格表面，包括桥面；偏移后位置超出地图网格时回退普通武器出口。部分特殊武器使用自己的发射系统，不受此设置控制。Lua FireWeapon 的 Origin 可单独覆盖一次射击的位置。

视觉效果 / 武器与单位表现

武器曳光

武器曳光在开火时绘制从武器出口飞向瞄准点的短光迹。武器绑定写在规则中，颜色和运动样式写在 art 配置中。

配置位置：rulesmd.ini 的武器节。

配置位置：artmd.ini 的曳光样式节。

每个单位按武器分别统计射击次数，原版连发的每一发分别计数。曳光终点使用开火时的目标位置，不跟随目标后续移动；武器伤害和命中时间仍由原版射击逻辑决定。

视觉效果 / 武器与单位表现

持续光束

持续光束让支持的武器在两次射击之间继续显示连接到目标的视觉效果；伤害和弹药仍按原有武器节奏结算。

同时启用多个原版光束标记时，按激光、电弧、辐射光束的顺序选择。失去目标、脱离射程、切换目标或停止后连接结束；再次开火建立新的连接。点地开火使用原有单次视觉效果。

杂项 / 独立规则

自定义拾取物

自定义拾取物放置在地图格上，地面步兵或载具进入后触发配置结果。它与原版箱子的数量和有效期相互独立。

注册与配置

Action、Actions 和 RandomActions 是互斥的结果配置方式。拾取时 Self 和 Target 指拾取单位，VictimLocation 指拾取格；同格有多个单位时由对象 ID 最小者拾取。

生成与移除

生成位置不可用时会在附近搜索；移除结果不影响原版箱子。拾取物随存档保留。

杂项 / 独立规则

自定义超武

ActionSequence 是由流火提供的点选超武类型，可以顺序执行位置类结果、玩家奖励或 Lua 脚本。超武通过原版超武注册和建筑授权使用。

位置类 INI 结果使用 Point，资金和科研点结果使用 Owner；RunScript 不显式指定目标。需要治疗、伤害或移动具体单位时，可由 Lua 查询单位后传递句柄。

超武脚本可读取 ctx.point、ctx.owner、ctx.superWeapon 和 ctx.castId；初始 ctx.self、ctx.target 为空。状态和延迟任务属于该次超武调用，详见Lua 上下文。

额外说明

素材引用

本节汇总图标、界面文字、音效和动画的引用规则。各功能的具体参数见对应小节。

图标与贴图

科研和主动技能支持 PNG 或游戏可加载的 PCX 图标，目标指示器使用透明 PNG。PNG 的透明区域由 alpha 通道决定，不透明的黑色像素不会自动透明。主动技能图标会裁切到按钮开口，重要内容应放在中央。

配置字段见科研项目、主动技能图标、目标指示器和武器曳光。

文本与名称

科研、主动技能和单位头顶注释可配置文本或文本 ID。科研项目的 Name、Summary、Detail 和 TargetLabel 分别用于名称、简述、详情和作用对象显示。

部分单被动科研详情支持 {amount}、{count}、{chance}、{cooldown} 等占位符，资金奖励支持 {credits}。多结果被动的金额占位符取首个结果；持续状态和组合科研的自定义详情不按每个子结果展开。

配置字段见科研项目、主动技能名称和单位头顶注释。

音效

科研界面可使用内置提示音或外部 WAV；PlaySound 结果使用原版音效 ID，或以 wav: 开头的文件路径。外部 WAV 支持未压缩 PCM、8 或 16 位、单声道或立体声，采样率为 8000–48000 Hz，文件最大 16 MiB。

配置字段见科研提示音和一次性结果参数。

动画与染色

流火可引用游戏或模组已注册的动画类型，也可通过 Lua 创建和移动动画。动画类型 ID 与图像文件名是不同概念。

配置字段见被动动画与染色、一次性结果参数和 Lua 可移动动画。

额外说明

Starfall.log 日志

Starfall.log 是流火的诊断日志，位于游戏目录中。遇到配置不生效、技能未出现或 Lua 脚本异常时，可以先查看这个文件。

日志内容

  • 配置问题：无效的字段、数值或组合，以及未注册的被动、单位类型和其他引用。
  • 科研问题：可能包含项目节、字段、数值和错误原因；能确定来源时也会记录文件行号。
  • Lua 问题：脚本加载或执行错误，以及相关文件、回调函数和错误位置。
  • 资源问题：部分图像、音效或曳光样式缺失及配置无效信息。

日志通常以追加方式写入，文件中可能包含之前运行留下的信息。检查时应结合最近一次运行的记录及对应配置；合并规则中的问题不一定能定位到原始文件或具体行号。被动配置无效时，依赖它的科研或授予预设也可能无法使用。

日志用于辅助定位问题，并不保证记录所有游戏异常。Lua 的配置和运行限制见 Lua 脚本入口与 Lua 运行环境与限制。
