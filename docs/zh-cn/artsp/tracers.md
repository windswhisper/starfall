# 武器曳光

[返回目录](../index.md)

武器曳光在开火时绘制从武器出口飞向瞄准点的短光迹。武器绑定写在规则中，颜色和运动样式写在 art 配置中。

配置位置：`rulesmd.ini` 的武器节。

```ini
[武器 ID]
Tracer=(art 样式节 ID)
; 指定曳光样式。
; 默认值：未设置，不绘制曳光。

Tracer.Every=(正整数)
; 每隔多少次射击绘制一次曳光。
; 默认值：1；范围：1–2147483647。
```

配置位置：`artmd.ini` 的曳光样式节。

```ini
[曳光样式 ID]
Gradient=(布尔值)
; 是否从尾部颜色渐变到头部颜色并淡出尾部。
; 默认值：no，整条曳光使用 Color。

Color=(红,绿,蓝)
; 曳光整体颜色；启用渐变时为头部颜色。
; 默认值：255,205,96；每个分量范围：0–255。

TailColor=(红,绿,蓝)
; 启用渐变时的尾部颜色。
; 默认值：210,92,28；每个分量范围：0–255。

Length=(正整数 leptons)
; 曳光最大可见长度。
; 默认值：96；范围：1–4096；256 leptons 为一格。

Width=(正整数像素)
; 曳光宽度。
; 默认值：2；范围：1–8。

Speed=(正整数 leptons 每帧)
; 曳光的视觉移动速度。
; 默认值：192。
```

每个单位按武器分别统计射击次数，原版连发的每一发分别计数。曳光终点使用开火时的目标位置，不跟随目标后续移动；武器伤害和命中时间仍由原版射击逻辑决定。
